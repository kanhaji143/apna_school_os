APNA SCHOOL OS — WINDOWS 11 ERROR 4551 & REMOTE DEPLOYMENT TROUBLESHOOTING LOG
================================================================================
फ़ाइल का उद्देश्य: AnyDesk, TeamViewer, WhatsApp अथवा इंटरनेट द्वारा भेजे गए 
सॉफ़्टवेयर पैकेज को Windows 10/11 पर इंस्टॉल करते समय आने वाली त्रुटियों (विशेष रूप से
Error 4551: Temporary Directory Policy Block) का स्थायी निवारण एवं तकनीकी समाधान।

--------------------------------------------------------------------------------
1. हालिया घटना विवरण (Incident Log — 22-Nov-2026):
--------------------------------------------------------------------------------
• क्लाइंट / टेस्ट पीसी कॉन्फ़िगरेशन:
  - ऑपरेटिंग सिस्टम : Windows 11 Pro (OS Build 26142 — Windows 11 24H2 Preview)
  - प्रोसेसर / रैम   : Intel Core i5-8350U @ 1.90 GHz | 8.00 GB RAM
  - ट्रांसफर माध्यम  : AnyDesk Remote Session / WhatsApp
• प्रदर्शित त्रुटि (Error Popup):
  "Unable to execute file in the temporary directory. Setup aborted. 
   Error 4551: An Application control policy has blocked this file."

--------------------------------------------------------------------------------
2. त्रुटि के मूल कारण (Root Cause Technical Analysis):
--------------------------------------------------------------------------------
कारण 1: Windows 11 Smart App Control (SAC) & Temp Folder Restriction
  - AnyDesk या इंटरनेट से आई फाइलों पर Windows स्वतः "Mark-of-the-Web (Zone.Identifier)"
    सुरक्षा टैग लगा देता है।
  - जब Inno Setup (Setup_Apna_School_OS.exe) चलता है, तो वह एक आंतरिक हेल्पर 
    फाइल Windows के %LOCALAPPDATA%\Temp फोल्डर में निकालता है।
  - Windows 11 की नई Application Control Policy टेम्परेरी फोल्डर से अनसाइंड 
    एग्जीक्यूटेबल चलने पर रोक लगा देती है, जिससे Error 4551 उत्पन्न होता है।

कारण 2: पोर्टेबल ज़िप को बिना Extract किए सीधे अंदर से चलाना
  - Apna_School_OS_Portable_v2.0_NoInstall.zip को एक्सट्रैक्ट किए बिना 
    ज़िप के अंदर से सीधे Apna_School_OS.vbs चलाने पर Windows उसे टेम्प सैंडबॉक्स
    में भेजता है, जहाँ node.exe और सर्वर फाइलें नहीं मिलतीं।

--------------------------------------------------------------------------------
3. स्थायी 1-क्लिक समाधान (Permanent 1-Click Solution):
--------------------------------------------------------------------------------
हमने पैकेज में "1_CLICK_UNBLOCK_SETUP.bat" जोड़ दिया है। 
यह स्क्रिप्ट दो काम स्वतः करती है:
  [A] Unblock Files: PowerShell 'Unblock-File' चलाकर AnyDesk/इंटरनेट के सारे ब्लॉक हटाती है।
  [B] Temp Redirection: TEMP डायरेक्टरी को Windows के ब्लॉक किए गए AppData\Temp से हटाकर
      लोकल फ़ोल्डर (.\setup_temp) पर रीडायरेक्ट कर देती है।
  👉 परिणाम: Inno Setup बिना किसी नीतिगत रुकावट के 1 सेकंड में शुरू हो जाता है।

--------------------------------------------------------------------------------
4. ऑपरेटर / डेवलपर हेतु मानक संचालन प्रक्रिया (Standard SOP):
--------------------------------------------------------------------------------
विधि A: EXE इंस्टॉलर के लिए
  1. पैकेज की सभी फाइलों को सामान्य फोल्डर में रखें।
  2. "1_CLICK_UNBLOCK_SETUP.bat" पर राइट-क्लिक करके 'Run as administrator' चलाएं।
  3. सेटअप सामान्य रूप से पूरा हो जाएगा।

विधि B: पोर्टेबल वर्शन (NoInstall) के लिए
  1. ज़िप फ़ाइल पर राइट-क्लिक करें -> "Extract All... (सभी निकालें)" चुनें।
  2. किसी भी फोल्डर (जैसे C:\ApnaSchoolOS या Desktop) में एक्सट्रैक्ट करें।
  3. अब अंदर मौजूद "Apna_School_OS.vbs" पर डबल-क्लिक करें।

मैन्युअल अनब्लॉक विधि (यदि आवश्यक हो):
  - Setup_Apna_School_OS.exe पर राइट-क्लिक करें -> Properties (गुण) -> सबसे नीचे 
    "Unblock" (अनब्लॉक) चेकबॉक्स पर टिक करें -> Apply -> OK दबाएं।
